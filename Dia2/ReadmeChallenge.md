# Project title: E-commerce Shipping Calculator
## Description: This software is a specialized tool for logistics management. It is a Python-based solution designed to simplify the calculation of delivery fees for online businesses. The program ensures that shipping costs remain transparent and accurate for every customer transaction.
How it works
1 Data Collection: The system requests the origin city distance and the package weight from the user.
2 Logic Processing: The script multiplies the total kilometers by a fixed price of 500.
3 Discount Application: The algorithm checks the membership status and applies a price reduction if the user is a member.
4 Final Output: The console displays the final cost to the user in a clear format.

< Status: We are currently updating the code to include global shipping rates and improved weight-based surcharges.

Features
Distance Tracking: Calculates cost based on total kilometers.

Weight Input: Allows for future scaling (e.g., adding surcharges per kg).

Membership Integration: Toggle between standard and discounted rates easily.>
